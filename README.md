# Basil Aldoss — Workshop portfolio

Open `index.html` in a browser, or serve this folder with your usual local web server. No installation or build step is needed. Publish this folder as a static site when ready.

The workshop design is adapted from the supplied `Basil_Portfolio` reference. The existing biography, skills, employment history, project descriptions, education, certifications, community work, and contact information are retained.

## Explore

- Start or pause the cutaway engine, change its animation speed, and select its moving parts for explanations.
- Switch between the workshop and blueprint palettes. Your selection is remembered locally when browser storage is available.
- Select a workbench object or its label to open the corresponding real project. The project notes below also work without JavaScript. On narrow screens, scroll the workbench sideways to see all three objects.
- Use the sketchbook tabs to explore linkage, gear, and spring motion studies. Arrow keys, Home, and End navigate the tabs.
- Use the footer to pause animations. System reduced-motion preferences are respected; the engine can be started independently.

The engine, workbench objects, and sketchbook are illustrative SVG studies. The project notes describe the actual work. Fonts load from Google Fonts when online, with system font fallbacks.

Files: `index.html` contains the page content and SVG illustrations; `assets/styles.css` defines the responsive layout and both palettes; `assets/site.js` supplies the interactions.
